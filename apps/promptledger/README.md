# PromptLedger

AI work audit log for **agencies** that bill clients for AI-assisted work.

Capture prompts, outputs, and notes (paste, page selection, or right-click menu), tag by client, export markdown.

## Stack
WXT (MV3) · React 19 · TypeScript · Tailwind v4 · `chrome.storage.local`

```bash
npm install && npm test && npm run build
```
