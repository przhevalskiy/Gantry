# PayBump — permission justifications

Paste into Chrome / Edge / Firefox permission justification fields as needed.

| Permission | Justification |
|------------|----------------|
| `storage` | Save user settings and macros and settings locally on the device. Not transmitted by the local version. |
| `activeTab` | When the user opens the popup or invokes an action, access the current tab to perform insert the selected macro into the focused field. |
| `scripting` | Run a user-initiated script to insert/expand macro text the user chose. |
| `tabs` | N/A |
| `contextMenus` | N/A |
| Host permissions | Macros can be inserted into email/support/billing tools the user already uses. |

## Single purpose statement
PayBump’s single purpose is: Stripe and invoice dunning macros.
