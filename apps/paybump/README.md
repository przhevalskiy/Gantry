# PayBump

Failed-payment and invoice follow-up macros for **Stripe Billing** / indie SaaS dunning.

Starter macros (`;card`, `;d3`, `;final`, `;inv`, `;wire`), click-to-insert, shortcut expansion.

## Stack
WXT (MV3) · React 19 · TypeScript · Tailwind v4 · `chrome.storage.local`

```bash
npm install && npm test && npm run build
```
