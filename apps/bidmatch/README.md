# BidMatch

Highlight RFP and job-board keywords from your saved searches.

Ships with starter sets (skills, contract type, clearance/compliance). Works on USAJobs, SAM.gov, Indeed, LinkedIn jobs, and any page.

## Stack

WXT (MV3) · React 19 · TypeScript · Tailwind v4 · `chrome.storage.local`

## Develop

```bash
npm install
npm run dev
npm test && npm run compile && npm run build
```

## Who it serves

Freelancers, grant writers, and BD folks skimming long solicitations for fit.
